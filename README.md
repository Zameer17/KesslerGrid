## 🔬 Mathematical Formulation of Orbital Mechanics & Risk

```latex
1. Kepler's Equation for Eccentric Anomaly:
   M = E - e * sin(E)

2. Newton-Raphson Iterative Convergence:
   E_{n+1} = E_n - (E_n - e * sin(E_n) - M) / (1 - e * cos(E_n))

3. True Anomaly (nu):
   tan(nu / 2) = sqrt((1 + e) / (1 - e)) * tan(E / 2)

4. Heliocentric / Geocentric Distance:
   r = a * (1 - e * cos(E))

5. 3D Euclidean Conjunction Proximity:
   D_{AB} = sqrt((x_A - x_B)^2 + (y_A - y_B)^2 + (z_A - z_B)^2)
   Threat Condition: D_{AB} < 50.0 km  OR  RiskScore >= 0.70
```

## 📜 Smart Contract Snippet: Reentrancy-Safe Slashing

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract KesslerGridCore {
    address public admin;
    address payable public penaltyTreasury;
    uint256 public constant MIN_STAKE_AMOUNT = 0.5 ether;

    struct Satellite {
        string satId;
        address owner;
        uint256 stakedAmount;
        bool isRegistered;
        bool hasActiveThreat;
    }

    mapping(string => Satellite) public satellites;
    event CollateralSlashed(string indexed satId, address indexed owner, uint256 amount, string reason);
    event AvoidanceBurnExecuted(string indexed satId, address indexed operator, uint256 timestamp);

    /// @notice Slash collateral upon un-evaded conjunction and transfer ETH to insurance treasury
    function slash(string memory satId, string memory reason) public onlyAdmin {
        require(satellites[satId].isRegistered, "ERR_NOT_REGISTERED");
        uint256 amount = satellites[satId].stakedAmount;
        require(amount > 0, "No stake to slash");

        address originalOwner = satellites[satId].owner;

        // Checks & Effects: Zero out state before external transfer
        satellites[satId].stakedAmount = 0;
        satellites[satId].hasActiveThreat = false;

        // Interaction: Native ETH transfer to penalty treasury
        (bool success, ) = penaltyTreasury.call{value: amount}("");
        require(success, "ETH transfer failed");

        emit CollateralSlashed(satId, originalOwner, amount, reason);
    }
}
```

## 🚀 Quickstart & Local Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Zameer17/KesslerGrid.git
cd KesslerGrid
```

### 2. Automated 1-Click Startup (Windows)
Double-click `run_all.bat` or execute in PowerShell:
```powershell
.\run_all.ps1
```
*This automatically boots up the Hardhat EVM node, deploys `KesslerGridCore.sol`, launches the Python analytics engine, starts the Node.js backend, and serves the Vite WebGL dashboard!*

---

### 3. Manual Multi-Tier Startup (Linux / macOS / Windows)

#### Step A: Blockchain Node & Contract Deployment
```bash
cd MainBackend/KesslerGrid/contracts
npx hardhat node
# In a separate terminal:
npx hardhat run scripts/deploy.cjs --network localhost
```

#### Step B: Python AI Analytics Engine
```bash
cd analytics
python run.py
```
*Microservice active at:* `http://localhost:8000/docs`

#### Step C: Node.js Backend Gateway & Oracle
```bash
cd backend
node server.js
```
*API Gateway active at:* `http://localhost:5000/api/satellites`

#### Step D: WebGL Frontend Dashboard
```bash
# In the repository root:
npm install
npm run dev
```
*Interactive 3D Dashboard active at:* `http://localhost:5173`
